# 学習サイト・用語説明 不足知識まとめ

## 目的
AI先生が存在しないサイト名や曖昧な説明を出さず、初心者に使いやすい学習先と用語説明を返せるようにする。

## 学習用CTFサイト例

| サイト | 特徴 |
|---|---|
| OverTheWire | Linux・ネットワーク・権限の基礎学習に向く |
| picoCTF | 初心者向けCTFとして有名。幅広いカテゴリがある |
| TryHackMe | ガイド付きでWeb/基礎セキュリティを学びやすい |
| Hack The Box Academy | 体系的なセキュリティ学習向け |
| PortSwigger Web Security Academy | Web脆弱性学習に非常に向く |
| CryptoHack | 暗号分野の学習に向く |
| pwnable.kr | Pwn/Reversing系の練習向け |

注意：
- URLやサービス状況は変わるため、RAG内では「代表例」として扱う。
- 実在が曖昧なサイト名を生成しない。

## 初心者向け用語説明

### CTF
Capture The Flagの略。問題の中に隠された `flag{...}` のような文字列を見つける競技・学習形式。

### Forensics
ファイル、メモリ、通信ログなどを調べて痕跡を見つける分野。

### Steganography
画像・音声・文書などに情報を隠す技術。CTFでは隠されたflagを探す。

### Crypto
暗号やエンコードを扱う分野。復号、鍵推測、数学的性質の利用などがある。

### Web
Webアプリの挙動や脆弱性を調べる分野。SQLi、XSS、IDOR、Cookieなどが出る。

### Reversing
実行ファイルを解析し、内部処理や正しい入力を調べる分野。

### Pwn
プログラムの脆弱性を利用して制御を奪う分野。BOFなどが代表例。

## 回答時の注意
- 初心者向けには、最初に一文で意味を説明する。
- その後に具体例を出す。
- 難語はその場で補足する。
