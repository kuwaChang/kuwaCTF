# Misc ナレッジ

## ゼロ幅文字（Unicode）

### ゼロ幅文字とは
画面には何も表示されないが、文字としてはデータに入っているUnicodeの文字。代表例:
- U+200B ゼロ幅スペース（ZWSP）: 単語の区切りを持たない言語で、改行してよい位置を示す
- U+200C ゼロ幅非接合子（ZWNJ）/ U+200D ゼロ幅接合子（ZWJ）: 文字や絵文字をつなげるか切るかを指定する。家族の絵文字は複数の絵文字をZWJでつないだもの
- U+FEFF: ファイル先頭ではBOM（バイト順マーク）として使われる
- U+2060 ワードジョイナー: その位置で改行させない

### CTFやセキュリティでのゼロ幅文字
- 文章の中に見えないメッセージを隠すステガノグラフィに使われる。2種類のゼロ幅文字を 0 と 1 に見立てて、2進数として読む問題が多い
- 文書に利用者ごとの見えない印を入れて、流出元を特定する電子透かしにも使われる
- 見た目が同じなのに文字列比較が一致しない、URLやユーザー名の偽装にも悪用される

### ゼロ幅文字の見つけ方
- `xxd file.txt`（(LinuxまたはWSL)）で16進表示する。UTF-8では U+200B は `e2 80 8b`、U+200C は `e2 80 8c`、U+200D は `e2 80 8d`、U+FEFF は `ef bb bf` と出る
- Python で `[hex(ord(c)) for c in text]` とすると、見えない文字のコードポイントも並ぶ（Windows と (LinuxまたはWSL)）
- 文字数を数えて、見た目より多ければ見えない文字が入っている

## Brainfuck

### Brainfuckとは
1993年に Urban Müller が作った難解プログラミング言語（esolang）。使う記号は次の8つだけ:
- `>` ポインタを右のセルへ動かす / `<` 左のセルへ動かす
- `+` 今のセルの値を1増やす / `-` 1減らす
- `.` 今のセルの値を文字（ASCII）として出力する / `,` 1文字入力してセルに入れる
- `[` セルの値が0なら対応する `]` の後ろへ飛ぶ / `]` セルの値が0でなければ対応する `[` へ戻る

### Brainfuckの例と解き方
- 例: `++++++++[>++++++++<-]>+.` は、8×8＋1＝65 を作り、`A` を出力する
- 記号以外の文字はすべて無視される（コメント扱い）
- CTFでは `+-<>[].,` だけが並んだ文字列が出たら Brainfuck を疑う。インタプリタ（CyberChef には無いので、Brainfuck インタプリタや Python で書いた実行スクリプト）で実行すると文字列が出てくる
- 似た言語に、`Ook.` `Ook?` `Ook!` の組み合わせで書く Ook! がある。Brainfuck の8命令を置き換えたもの

## ASCIIとUnicodeの違い
- ASCII は 7ビットで 128文字（0x00〜0x7F）を表す文字コード。英字・数字・記号と改行などの制御文字だけで、日本語は含まない
- Unicode は世界中の文字に番号（コードポイント、`U+3042` のように書く）を割り当てた規格。番号をバイト列にする方法（符号化方式）に UTF-8 や UTF-16 がある
- UTF-8 は ASCII の範囲をそのまま1バイトで表すので、英数字だけの文章は ASCII と同じバイト列になる。日本語は主に3バイト（例: 「あ」U+3042 は `e3 81 82`）
- CTFで `0x41` → `A` のような変換が出たら ASCII、`あ` や `U+` が出たら Unicode のコードポイントを疑う

## QRコードの誤り訂正レベル
- QRコードは、一部が汚れたり欠けたりしても読めるように、リード・ソロモン符号で誤り訂正のデータを持つ
- レベルは4段階で、復元できる割合の目安は L 約7%、M 約15%、Q 約25%、H 約30%
- レベルを上げると読み取りに強くなるが、同じ情報量でもコードが大きく（細かく）なる
- 中央にロゴを載せたQRコードが読めるのは、隠れた部分を誤り訂正で補っているから
- CTFでは、一部が欠けたり塗られたりしたQRコードでも読めることがある。読めないときは、欠けた位置検出パターン（3隅の四角）を描き直すと読めることがある
