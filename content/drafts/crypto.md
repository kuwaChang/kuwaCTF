## crypto3（手動でやるのはつらい奴）
- カテゴリー: crypto
- 着眼点:
  - 「20回エンコード」がキーワード。1回デコードしてまた同じ形式が出てくるなら繰り返し処理
  - 添付 `make_base64x20.py` が生成手順のヒント（何のエンコードを何回かけたか）
- 段階ヒント:
  - まず1回デコードして、結果がまた同じ文字種（Base64っぽい）か確認する
  - デコードをループで20回繰り返すスクリプトを書く
  - `Question.txt` の文字列を入力に使う

```python
import base64
s = open("Question.txt","rb").read().strip()
for _ in range(20):
    s = base64.b64decode(s)
print(s)
```

## crypto5（はい！それはφです！）
- カテゴリー: crypto
- 着眼点:
  - `φ` はオイラーのトーシェント関数（1以上n以下でnと互いに素な整数の個数）
  - 素数pなら φ(p)=p−1。合成数は素因数分解して計算
- 段階ヒント:
  - 1234, 5678 をそれぞれ素因数分解して φ を求める
  - 9973 が素数かを確認する（素数なら φ=9972）
  - 3つの φ を合計し、`FLAG{合計}` の形にする

```python
from sympy import totient
print(totient(1234)+totient(5678)+totient(9973))
```

## crypto6（素数なのか素数じゃないのか！どっちなんだい！）
- カテゴリー: crypto
- 着眼点:
  - 各数が素数かを判定 → 素数なら「×100」、非素数なら「+100」を、開始値1に順に適用して合計
  - 大きい数の素数判定はMiller–Rabin等（`sympy.isprime`）を使う
- 段階ヒント:
  - まず4つの数それぞれで True/False を確定させる
  - 例の計算ルール（True→×100、False→+100）を1から順に適用
  - 途中式を残して積み上げ、`FLAG{結果}` にする

```python
from sympy import isprime
nums=[999681217,999681186,140628287,140168112]
v=1
for n in nums:
    v = v*100 if isprime(n) else v+100
print(v)
```

## crypto7（RSA）
- カテゴリー: crypto
- 着眼点:
  - `n, e, c` が与えられた素朴なRSA。ヒント文の「素因数分解してくれるDB」は factordb を指す
  - `n` を `p*q` に分解できれば秘密鍵 `d` を作れる
- 段階ヒント:
  - factordb（http://factordb.com/ ）に `n` を入力して `p, q` を得る
  - `φ=(p-1)(q-1)`、`d = e^{-1} mod φ` を計算
  - `m = c^d mod n` を求め、バイト列に直して読む

## crypto8（SHA256）
- カテゴリー: crypto
- 着眼点:
  - 「"FLAG" という文字列のSHA256ハッシュ値」を求める問題
  - ハッシュは元に戻せないが、計算するだけなら簡単
- 段階ヒント:
  - 文字列 `FLAG`（4文字）をSHA256にかける
  - 出力の16進64桁を、指定のフラグ形式に当てはめる

```sh
printf 'FLAG' | sha256sum
```

## crypto9（easy_RSA）
- カテゴリー: crypto
- 着眼点:
  - `private-key.pem` / `public-key.pem` / `target.encrypted` が揃っている
  - 「どちらの鍵を使うか」＝復号は秘密鍵を使う
- 段階ヒント:
  - 秘密鍵で暗号文を復号する（OpenSSLやPythonのcryptographyライブラリ）
  - 公開鍵は暗号化・検証用であることを確認する

```sh
openssl pkeyutl -decrypt -inkey private-key.pem -in target.encrypted
```

## crypto10（CodeDecode）
- カテゴリー: crypto
- 着眼点:
  - `46 4c 41 47 ...` は `0-9a-f` の2桁区切り＝16進（Hex）
  - 「コンピュータの文字表現の一つ」＝ASCIIコード
- 段階ヒント:
  - 各2桁を16進として1バイトに変換する
  - バイト列をASCII文字に直すと読める
  - 先頭 `46 4c 41 47` が `FLAG` になるか確認する

```sh
echo "46 4c 41 47 7b ..." | xxd -r -p
```

## crypto12（%%__%%）
- カテゴリー: crypto
- 着眼点:
  - `%E5%BE...` は URLエンコード（パーセントエンコード）
  - URLデコードすると日本語の歌詞になり、途中に Base64 の断片が混ざる
- 段階ヒント:
  - まずURLデコードして日本語文を復元する
  - 文中の `FLAG{...}` 内に見える英数字が Base64 になっていないか確認する
  - その部分だけを取り出して再度デコードすると本当のフラグになる（多段変換）

## crypto13（easy_encrypto）
- カテゴリー: crypto
- 着眼点:
  - 添付 `EXOR.py` のとおりXOR暗号。「ちゃんと暗号化されているのか？」は鍵が弱い示唆
  - XORは同じ鍵で戻せる。既知平文 `FLAG{` から鍵を推測できる
- 段階ヒント:
  - `EXOR.py` を読み、鍵と入力（暗号文）を把握する
  - 暗号文の先頭と `FLAG{` をXORして鍵を復元する
  - 鍵が短い繰り返しなら全体に適用して復号する
